# XRD & AFM 数据分析

一套面向 AlN / ScAlN 薄膜表征的本地数据处理工具，覆盖两类常规测试：

| 数据类型 | 输入 | 输出 |
|---|---|---|
| **XRD** 摇摆曲线 / 2θ-θ 扫描 | `.xrdml`（Panalytical）、`.txt`、`.xy` | 峰位、FWHM、拟合图、汇总表 |
| **AFM** 表面形貌 | `.ibw`（Asylum MFP-3D / Cypher 的 ARDF v2） | Ra/Rq/Rmax/Rz、表面类型、晶粒尺寸、颗粒统计、2D/3D 图、Word 报告 |


---

### 使用


### XRD 标签页

- **扫描类型先判断，再算**：
  1. 读 `.xrdml` 里的 `<scan scanAxis="...">`（最可靠；**先判 2θ 再判 ω**，因为 `2Theta-Omega` 这类轴名同时含两者）；
  2. 看文件名关键词（`omega` / `rocking` / `2theta` …）；
  3. 按角度跨度猜：> 5° 判 2θ，< 1.5° 判 Omega；
  4. 都判不出来 → 弹窗让你选（选择会被记住，不会每个文件问一遍）。
  也可以在上方下拉框里强制指定。
- **Omega 摇摆曲线**：横轴 ω，输出 FWHM。直接半高法 + Voigt / Lorentzian / Gaussian 三种拟合，附 R²、拟合窗口、可选残差面板。
- **2θ-θ 扫描**：横轴 2θ、**纵轴取 log**、**不出 FWHM**，只在每个峰顶标注峰位（如 `36.06°`）。峰位在扣背景后的曲线上判定，图上仍画原始强度，弱峰也能看清。
- 改参数（扫描类型 / 拟合方法 / 拟合窗口 / 扣背景 / 残差）会按已读入的坐标重算，不用重新选文件。

### AFM 标签页

- 解析 `.ibw` 的 Height 通道，一阶最小二乘去倾斜，输出 Ra / Rq / Rmax / Rz / Ssk / Sku。
- **先判表面类型，再决定统计方式**（与 Python 版同一套判据）：
  - **连续晶粒织构** → 分水岭晶粒分割，输出晶粒数、等效圆直径（均值/中位/标准差/CV/P90）、平均长轴、面密度，并出晶粒边界图与晶粒尺寸分布。
  - **平坦基底 + 孤立颗粒** → 高斯背景扣除 + 自适应阈值分割，输出颗粒数、面密度、等效直径、高度、覆盖率，并出颗粒标记图与颗粒尺寸分布。
- 判据：`Ra/Rmax < 0.06`，或 `颗粒覆盖率 > 0.2% 且颗粒均高 > 3Ra（且颗粒数 ≥ 5）` → 平坦 + 颗粒；其余 → 晶粒织构。判定结果写在表 1 的「表面类型」列，鼠标悬停可看具体依据。
- 出图：Gwyddion 色标 + 色标条（标 nm）+ scale bar 的 2D 高度图、3D 形貌、晶粒分割／颗粒标记图，以及总览、Ra/Rq 对比、晶粒与颗粒尺寸分布。

### scale bar：默认自动，需要时才调

- **默认自动**：每张图按**自己的扫描范围**取约 1/4 的「整齐」长度，只从 `1 / 2 / 5 × 10ⁿ` 里挑。

  | 扫描范围 | 5 µm | 3 µm | 2 µm | 1 µm | 0.5 µm |
  |---|---|---|---|---|---|
  | 自动长度 | 1 µm | 500 nm | 500 nm | 200 nm | 100 nm |

  不足 1 µm 时标注自动改用 nm，避免出现 `0.2 µm` 这种不好读的写法。
- **需要固定长度**：在某张图卡片里的 `scale bar` 输入框填数值（单位 µm），回车或失焦即重绘该图与总览；清空输入框或点「恢复自动」回到自动值。数值会被钳制在扫描范围的 2%–90%，防止短到看不见或长到出框。
- 页面顶部的「全部恢复自动」一键把所有图改回自动。
- scale bar 只影响标注，不影响任何统计值；混用不同扫描范围的批处理时，各图各算，不会互相顶掉。


## 计算口径

### XRD

- **背景**：非对称最小二乘（ALS），`lam=1e7, p=0.01`，10 次迭代。矩阵为五对角对称正定阵，用**带状 Cholesky** 求解，与稠密求解同解，3000 点从数秒降到毫秒级。
- **寻峰**：Savitzky-Golay 平滑（三次，窗宽约 1% 点数）后按「高度 ≥ 5% 峰值、突出度 ≥ 2% 峰值、最小间距 0.5% 点数」取峰；Omega 模式取突出度最大者为主峰。
- **直接半高法**：峰两侧半高处**线性插值**。
- **拟合**：默认在主峰 `±max(8×直接半高宽, 20 点)` 的局部窗口内做最小二乘，参数界限放开；Voigt 线宽用 Olivero 近似换算。
- **Voigt 函数**：复误差函数用 Weideman (1994) 36 阶算法，与 `scipy.special.voigt_profile` 相对误差约 `1e-14`。
- **R²**：`1 − SS_res/SS_tot`，在拟合窗口内计算。
- **2θ 模式**：不做拟合、不出 FWHM；纵轴为对数强度；峰位在扣背景后的曲线上判定。

### AFM

- **去面**只做一阶平面拟合（去样品倾斜），不做逐行滤波，因此 Ra 包含真实长波起伏。
- **粗糙度**：Ra/Rq 按全幅逐点计算；Rmax 为峰谷差；Rz 为五点法；Ssk/Sku 为偏度与峰度。
- **表面类型**：`Ra/Rmax < 0.06`，或（覆盖率 > 0.2% 且颗粒均高 > 3Ra 且颗粒数 ≥ 5）→ 平坦基底 + 孤立颗粒，此时不输出晶粒统计；其余 → 连续晶粒织构。两类互斥成表，不会重复计入。
- **晶粒分割**：σ=1 px 高斯平滑 → 归一到 0–1 → 以 `0.45 × P99` 为阈值取高度局部极大作种子（最小间距 3 px）→ 负高度分水岭（4 邻域）→ 面积 ≥ 12 px 计入，**触边晶粒剔除**。等效圆直径 `2√(A/π)`，长轴由区域二阶中心矩求得（与 `skimage` 的 `axis_major_length` 同定义）。
- **颗粒识别**：15 px（约 0.15 µm）高斯背景 → 相减得高通残差 → 残差 MAD 估计噪声 σ（`σ = 1.4826·MAD`）→ 阈值 `max(8σ, 3 nm)` → 8 邻域连通域 → 面积 ≥ 6 px 计为颗粒。
- **阈值自适应**：平滑表面 σ 小，可检出数 nm 级颗粒；粗糙表面 σ 大、阈值抬高，报 0 个表示「未检出高于噪声的孤立凸起」，不等于表面洁净，建议结合 2D 图或降低阈值复核。
- **scale bar**（仅网页版）：按每张图自己的扫描范围取约 1/4 的 `1/2/5×10ⁿ`，可在页面上逐图覆盖；只影响标注。

## 两端一致性

算法口径逐项对齐：扫描类型判断链、ALS 背景、SG 平滑、寻峰、直接半高法、三种拟合、表面类型判据、晶粒分割参数、颗粒阈值全部相同。数值对齐（同一批合成数据，Python ↔ 网页）：

| 项目 | 差异 |
|---|---|
| ALS 背景 | ~1e-9（相对） |
| SG 平滑 | ~1e-8 |
| 直接半高 FWHM | ~1e-11 |
| Voigt FWHM | ~1e-5 |
| Lorentzian / Gaussian FWHM | ~5e-4（LM 与 trust-region 的收敛细节差异） |
| AFM 粗糙度 | ~1e-7（相对，仅累加顺序不同） |
| 晶粒 / 颗粒计数 | 一致；晶粒边界在「等高平局」处可能差 1 px，统计值通常 < 2% |

实现上的已知差异：

- **分水岭**：Python 用 `skimage.segmentation.watershed`，网页用自写的「优先队列洪水」（二叉堆 + 4 邻域），思路相同，平局时的推进顺序不同。
- **拟合器**：Python 用 `scipy.optimize.curve_fit`（trust-region reflective），网页用带盒约束的 Levenberg–Marquardt。
- **表格格式**：Python 出 `.xlsx`（多 sheet），网页只出 UTF-8 BOM 的 `.csv`（Excel 双击可直接打开）。

## 已知限制

- `.ibw` 仅支持 ARDF v2 结构（MFP-3D / Cypher 常见导出）；标准 Igor Binary Wave 或 `.spm` 需另做解析器。
- `.xrdml` 支持 XRDML 2.0–2.2；其它命名空间会按 localName 匹配，但未逐一验证。
- 网页版一次建议不超过 ~40 个文件；AFM 的 512×512 单文件解析 + 晶粒分割约 0.5–1 s。
- 网页版晶粒分割用纯 JS 分水岭，超大图（> 1024²）会明显变慢，建议先裁剪或降采样。
- Word 里的图片是 PNG 内嵌，导出 PDF 时会二次压缩，送审建议直接用 PNG 原图。
- 表面类型是自动判定，边界样本（Ra/Rmax ≈ 0.06）建议看图人工复核。
